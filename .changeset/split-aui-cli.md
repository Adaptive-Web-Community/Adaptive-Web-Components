The `aui` command is published as `@adaptive-web/adaptive-ui-cli`. The library exports a compile API (`jsonToStyleSheet`, `compileStyleRulesToCss`, and related types), and `@adaptive-web/adaptive-ui/reference` has `referenceCompileContext`. Install the CLI package for `aui`; see the [migration guide](./MIGRATION.md).
