# Calendar

A calendar is a month as a grid of days (`role="grid"`), which the user moves through with the keys and selects one date in, or several:
the grid of the [ARIA date picker](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/examples/datepicker-dialog/), which a date picker
would show in a popover.

- Contract: `CalendarElement` and `CalendarParts` (`calendar.ts`).
- Behavior: `CalendarController` (`calendar.controller.ts`), which renders the grid in the `days` part, so every framework's template has
  the same, and the ISO date functions (`dates.ts`), which compute in UTC so no day shifts with daylight saving.

## What was taken from where

The source: FAST Foundation 3.0.0-alpha.33 (the archive).

| Aspect | FAST Foundation | Here |
| --- | --- | --- |
| Grid | A Data Grid of rows and cells, generated by templates | A native `<table role="grid">` in the shadow root, with column headers (`abbr` the full name) and cells, which the controller renders |
| Name | | The `label` attribute or slot, in the `label` part ([0016](../../../../docs/decisions/0016-a-control-is-labelled-as-its-native-element-is.md)), and the month shown name the grid; `hide-label` hides the label |
| Dates | `m-d-yyyy` strings in `selected-dates` and `disabled-dates` | ISO dates (`2026-10-27`), as a native date input's: `value`, `values`, the `value` attribute as the default, `min`, `max`, and `disabled-dates` |
| Selection | Selected dates, not selected by the calendar | One date, or several with `multiple`, toggled; `input` and `change`; a form control with the dates as its value |
| Keys | The Data Grid's, between cells | The date picker's: the arrows by a day and a week (swapped right to left), Home and End to the ends of the week, Page Up and Page Down by a month, with Shift by a year, Enter and Space to select; the month follows the focus |
| Tab order | The Data Grid's | The selected day, today, or the first of the month |
| Months | `month` and `year` | `month` and `year`, reflected, and buttons for the months before and after, named by those months in the locale, and disabled out of the range |
| Locale | `locale` (en-US by default), `Intl` formats per part (`day-format`, `weekday-format`, `month-format`, `year-format`) | `locale`, or the element's `lang`, or the browser's; the first day of the week from the locale (`Intl.Locale`), or `first-day`; the formats are `Intl`'s, short weekdays with their full names |
| Today | A `today` class | `aria-current="date"` |
| Days of other months | An `inactive` class | `data-outside` |
| Read only | `readonly`, which made it not interactive | `readonly`: the keys move, nothing is selected, `aria-readonly` |
| Weeks | `min-weeks` | The weeks of the month |

Considered and not taken:

- FAST Foundation's format attributes (`day-format` and the others): the locale's own formats are used; add them on the first real use.
- A date picker (a field that opens a calendar in a popover): when it is needed, it is a Picker-like field around this calendar.
- A native `<input type="date">`: its picker can't be styled, and it has no inline calendar.
