# Card

A container for content. It has no behavior and no parts, so it has no contract here: a binding is an element with a default slot.

## What was taken from where

| Aspect | FAST Foundation | Here |
| --- | --- | --- |
| Element | An element with a default slot | FAST Foundation |
| Semantics | None | None. The author gives a role (`article`, `group`, `region`) when the content needs one |

Considered and not taken: an interactive card (a card that is a link or a button) is a separate pattern, with its own focus and activation.
